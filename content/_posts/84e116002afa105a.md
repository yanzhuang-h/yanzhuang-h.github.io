第一天，神说，要有光，于是光明和混沌分开来。

这句话应该是《创世记》里的，不过我并不相信任何上帝，心中只有马克思主义。


还记得本科的时候，大概是 23 年的样子，当时刚从电气工程转入计算机系，怀着想要创作些什么的热情，以及在互联网上留下些什么痕迹的着迷，搭建一个个人网站。操作起来其实并不复杂，只是通过了 GitHub 以及 Hexo。

GitHub 原生的访问地址并不清晰优雅，于是买了一个域名，记得是叫 `zoneyhu.top`，十几块钱一年。当时 AI 还没有发展成现在这样，大量的有效信息仍然需要去查找 CSDN，凭借着应该算是技术的热情，调试到深夜，最终成功部署了网站，记得那晚母亲过来催了我几次让我早点休息。其中的艰辛，我想也是我们那一代——作为最后的代码手艺人——才能懂得。就像现在有一个名词叫 vibe coding，非要定义一下的话，我们那时候大概算是 hand coding 吧。

后来到了考研时，其实就考虑过完成一个作品集。想法早就有之，过年回家和朋友闲聊，得知友人 Z 进了设计类专业，求职时招聘方通常会要求提供一个作品集。也是从那时起，我在想自己是不是也可以做出一个这样的东西——就像《星露谷物语》的作者，起初也是为找工作而准备一个设计项目。

计算机和其他工科在求职上确实很不一样。可能因为我不太了解其他专业，但我只知道，现在计算机专业似乎一入学便只有几条既定路线可走，性价比最高的可能就是疯狂学后端（比如 Java）、学算法、刷力扣，能尽早实习就赶紧去——学校里教的东西，并不足以把一张大厂的 offer 送到你面前。

考研初试结束后，看着早已弃置的旧网站，加上心中对能否进入复试的不确定性，实在没有心情去打理这些。所幸最近时间稍微空闲一点，想着重建一下当时的想象空间，也算是创作出一点东西——就像我一直以来在做、或是想要做的那样，用三个字来概括，就是「表达欲」吧。

这篇文字其实写了很久，因为情绪原因，或是其他一些事情，磕磕绊绊到现在才真正想要去完成它。真正发布时可能时间会更晚吧，但毕竟我现在已经开始推进，总会在近期落地的。因此文章里经常会冒出一些类似呓语般的句子，好像不合时宜，却又必要地记录了我最近的心境与情绪，就像马尔克斯的非线性叙事一般。


最近哈尔滨经常会起大雾，随着太阳落下，乳白色的烟雾便四散开来。昨天我买下了域名 `huzhuangyan.com`，花了 76 块钱，算是比较贵的域名了——如果选 `.world` 结尾，其实只需要 13 块钱，但最终还是选用了 `.com`。


所以我现在就在构思，到底该如何向别人讲述这个故事。我将会以这个网站为起点构建我的帝国——“这是我帝国的基石”，哈哈哈哈。刚好最近在看 *Better Call Saul*，Saul 在拿到 Kettleman 一家的封口费后，就是这么说的。

就像我之前一直在做的那样，我确实需要打造一个个人IP，包括小红书、抖音、甚至矩阵号等等平台。但是这样就需要控制好一个边界：我到底要做到什么地步、去输出什么内容？我甚至想把工作相关的东西也放上来，这就必须严格做好分区。归根结底，个人网站首先应该完完全全为我自己服务，当然，帮助建设个人 IP 也是它至关重要的一部分。因此，面向公众的个人 IP 应该作为主舞台去打造；而我自己暂时不想公开的东西——比如找实习的文档、沉淀的私人知识库——则需要把工作、生活与个人 IP 彻底分开，只收进页面里一个很小的角落，不显眼，也不完全开放，这就得把安全与权限问题考虑进去。

暂时就想到这些，我觉得最重要的还是以一个东西为主线，即建设这个网站，先讲述一个完整的故事：认真设计首批放进来的内容、规划 UI 视觉与整体风格，同时解决好自动化的问题——做这些事，必须尽可能地简洁与方便。

这就是我一直以来想去做的事情。现在有了 AI，一切方便了很多，我可以真正为自己建立一个无论是知识也好、作品也罢、完全属于自己的东西，同步我所有的文档、作业、感想等等。我有预感，这项工程会持续很久很久，未来很长一段时间我都会不断地去打磨它。这在某种程度上也兑现了我的创作欲——就像我一直念叨的那样，我想要留下些什么。而且有了 AI 之后，这世上便有了一个至少完完全全读过我所有创作的存在——可以这么说吗，一定程度上的「Totally Digital ME」。

我还想从某本名著、书籍、专辑或是其他作品里，为网站汲取一点文学气息。也许我的个人助手可以叫做 Friday，算是致敬儿时读过的《鲁滨孙漂流记》（其实我也该把小时候读过的书重新翻一遍，再产出点新东西）。最近觉得给 Friday 用希腊字母编号蛮不错的——α、β、γ 等等，也算是致敬了 Claude、OpenAI 和 Gemini 的命名方式。

另外，我想把网站每个版本的快照都保留在一个小角落里，这样无论是别人还是我自己，都能看到它是怎么一步步进化的——这也正是我在做的「[达尔文版块](/evolution/)」，抑或是叫《天演论》or Evolution。


我要用 AI 帮我管理、整理所有的文档，这简直完成了我之前一直想做、却从来没有动手去做的事情！！


Kim 在面试时被问道：*"What do you want?"* ——答案是 *"More."* 这让我想起准备考研复试时，偶然点进一个收集[中科大历年机试题的网站](https://zdszero.github.io/ustc-graduate-guide/posts/)，扉页上只有很简单的一句话：*less is more*。过去很多时间我都在追求简洁优雅，但其实我想要的东西很多。我问了问自己到底想要什么，我想，我的回答也应该是 *more*。

另外，最近在搭建个人网站，以及为了买一枚银戒指而在小红书上收集整理信息时，我越发觉得「定制化」非常重要。信息检索本身就是一种能力，以前我习惯把它称作「搜商」，和智商、情商并列，现在大家更多把它叫做「信息差」。定制化能让人省去大量筛选的精力，又能直接得到合自己口味的东西，何乐而不为？以后这种形态的产品只会越来越多，甚至会出现专为某一次特定场景定制的应用——拿 App 举例，AI 极大地降低了开发一个网站或 App 的成本，专门服务于一场婚礼、一次旅行的数字产品，必然会被追求独特性的人青睐（当然，前提是得有足够好的售后接得住这份独特）。

这么一说，倒像是在给自己打广告了。但我确实就是在构建我的作品集：我要像写诗一样写每行代码，不止是一个 coder，更是一个 *poet* 或是 artist。


一切都好，S'all good, man.


本来这些话是要用在开头煽情的：
最近沉寂了很久，就是一直在做这个事情，想要打造一个个人 IP，就需要把自己的所有社媒账号统一起来，作为自己对外的表达窗口。如果有人喜欢，那很好，说明我的表达在某种程度上还不算太偏离主流价值；在此基础上，再去传递自己独特的意识，用文字链接创作——这就是我的终极想法，the ultimate goal~

网站正在持续优化中，创作也一直在继续。你现在看到的，永远都是一个在持续自进化的版本（RSI 说是）。如果你有一些创意想要实现，或者想向我提出一些建议，欢迎随时联系我——welcome for all！

而现在，如果要用一些文字来铺垫我往后的整个叙事，那我愿意用这一篇。谢谢你们的观看。


神看着一切所造的都甚好。有晚上，有早晨，是第六日。
